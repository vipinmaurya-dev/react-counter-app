# React Mini Projects

A collection of small React projects built to practice React concepts and improve development skills.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## Projects

| Project | Description |
|---|---|
| Counter | Increment, Decrement and Reset |
| Like Button | Like and Unlike functionality |
| Form Control (Multiple useState) | Form handling using multiple state variables |
| Form Control (Single useState) | Form handling using a single object state |

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

## Purpose

To learn React fundamentals through practical mini projects.
